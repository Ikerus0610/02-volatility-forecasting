# ES Session Probabilities
Python 3.12. Install with `python -m pip install -r requirements.txt`. Run `streamlit run app.py`. Yahoo ES=F supplies recent half-hour bars. Opening the dashboard archives available completed labels. Keep the SQLite database on persistent storage (ES_LAB_DB can set its path). Both processes must use the same path.

## OptionsData
Set OPTIONSDATA_API_KEY privately in your shell. Run `python optionsdata.py --probe` to test SPX access. To probe historical prints, add --osi with the exact quoted OSI including spaces and --date YYYY-MM-DD. A successful empty response is not proof of a complete day. See https://optionsdata.ai/readme.

Run `python optionsdata.py --capture` once per regular trading day between 16:16 and 16:59 America/New_York, for example at 16:25 using a scheduler on your own always-on machine. One fresh snapshot per day is stored; repeated captures keep the first. Scope is the closest listed expiration AFTER the signal date, across SPX/SPXW contracts returned for that expiration. This intentionally excludes expiring contracts; the result is not total market volume. Missing vendor counts cause rejection rather than being imputed. Completeness of the returned chain and vendor volume convention need confirmation with the account. No raw chains are bundled.

## Interpretation
Empirical up rate by prior put share (<45%, 45–55%, >55%), shrunk by ten pseudo-observations toward the historical frequency. Estimates begin after 30 paired, non-flat outcomes. Walk-forward Brier loss compares the volume model against the expanding base rate on identical dates. Thresholds are research choices. Holidays follow the US cash-equity calendar; missing boundary bars are excluded. ES=F is a rolling vendor series: futures roll effects can affect close-to-close labels. For longer backtests supply licensed contract-level ES bars and a historical option universe available as of each date. The REST probe does not backfill an expired chain. Historical evaluation only uses snapshots actually captured; run the app regularly to retain outcomes beyond Yahoo's rolling history. No measured predictive edge is asserted.

## Streamlit Community Cloud
Deploy this branch with app.py at the root and Python 3.12. Under Advanced settings → Secrets set OPTIONSDATA_API_KEY to a quoted string. Open the sidebar and select Check SPX access to discover the expirations allowed by the account. Save today's volume is available during the indicated capture window. Local SQLite storage on Community Cloud should be treated as temporary; collecting a permanent training history requires persistent storage and a scheduled capture process. Restrict app access to the intended audience under the provider agreement.
